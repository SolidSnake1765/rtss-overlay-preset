# Установка

Нужен только **RivaTuner Statistics Server 7.3.7 или новее** —
[отдельно, с сайта Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).
MSI Afterburner, HWiNFO и AIDA64 не нужны.

## Автоматическая (рекомендуется)

1. Скачайте архив: на странице репозитория **Code → Download ZIP** (или последний релиз) и распакуйте в любую папку.
2. Запустите **`install.bat`** и подтвердите запрос прав администратора.
3. Ответьте на вопросы:
   - **язык** установщика — русский или английский;
   - **шрифт** — `1` Bahnschrift (по умолчанию) или `2` Unispace;
   - **основной вид** — `1` большой (по умолчанию) или `2` компактная строка: какой показан после запуска RTSS;
   - **горячие клавиши** — откроется окно: щёлкните в поле и нажмите нужное сочетание, «Очистить» — не назначать.
   Ставятся оба вида оверлея — большой и компактная строка; переключаются по кругу одной клавишей.
4. Дождитесь «Готово». RTSS перезапустится уже с оверлеем.

### Что делает установщик

| Шаг | Что происходит |
|---|---|
| Поиск RTSS | по реестру; проверяется версия ≥ 7.3.7 |
| Резервная копия | `%ProgramData%\RTSS-Overlay-Preset\backup\<дата>` — всё, что будет изменено |
| Драйвер PawnIO | ставится тихо, если его нет (нужен для датчиков платы, процессора и таймингов памяти) |
| Файлы | в `RTSS\Plugins\Client\LHMDataProvider\`: LibreHardwareMonitor 0.9.6, `Exporter.dll`, модули PawnIO |
| Железо | процессор, видеокарта, плата, память; все датчики ищутся по названию, без жёстких номеров |
| Оверлей | `RTSS\Plugins\Client\Overlays\rtss-overlay-preset.ovl` — оба вида в одном файле, собранный под ваш ПК, + `rtss-overlay-preset-icons.png` (стрелки ↓↑ компактной строки) |
| Настройки RTSS | см. ниже |
| MSI Afterburner | если в нём включён свой оверлей — выключается только он |

### Какие настройки RTSS меняются и зачем

| Настройка | Значение | Зачем |
|---|---|---|
| Show On-Screen Display | вкл. | иначе оверлея не видно |
| On-Screen Display rendering mode | **Raster 3D** | только в этом режиме RTSS берёт шрифт из пресета |
| Отображать целое значение частоты кадров | вкл. | FPS вида «61.3» не помещается в своё поле |
| Плагины OverlayEditor и HotkeyHandler | вкл. | первый рисует оверлей, второй — горячие клавиши |
| Start with Windows | вкл., если было выключено | без запущенного RTSS оверлея в играх нет |
| Запускать в минимизированном состоянии | вкл. | RTSS стартует в трей, окно не выскакивает при входе в Windows |

Остальное (лимит кадров, Reflex, stealth mode, детект приложений) установщик не трогает.

### Горячие клавиши

| Действие | По умолчанию | Что делает |
|---|---|---|
| Показать / скрыть оверлей | Ctrl+Alt+Num 0 | включает и выключает оверлей |
| Сброс статистики | Ctrl+Alt+Num 1 | обнуляет средний FPS, 1% и 0.1% low. RTSS считает их с запуска игры, поэтому загрузки, ролики и меню тянут их вниз. Нажмите после загрузки уровня — статистика пойдёт только по геймплею |
| Скриншот | Ctrl+Alt+Num 2 | снимок экрана вместе с оверлеем в `Изображения\RTSS Screenshots` (PNG) |
| Оверлей: левый ↔ правый край | Ctrl+Alt+Num 4 | переносит оверлей к противоположному краю экрана |
| Оверлей: верх ↕ низ | Ctrl+Alt+Num 8 | переносит оверлей к верхнему или нижнему краю; вместе с предыдущей — в любой угол |
| Переключить вид | Scroll Lock | по кругу: большой → компактная строка → большой. Только одна клавиша без Ctrl/Alt — так RTSS считает нажатия; подойдёт любая, которая не нужна в играх (Scroll Lock, Pause) |

Оба вида лежат в одном файле, а какой показан, решает формула `key()` — счётчик нажатий клавиши, который ведёт
плагин HotkeyHandler (поэтому он должен быть включён). Счётчик считает одну клавишу, Ctrl/Alt он не видит — поэтому
сочетание здесь не назначить. После перезапуска RTSS включается основной вид — тот, что выбран при установке (без вопроса:
`install.bat -Style Full` или `-Style Compact`).

**Угол экрана.** Клавиши угла — «модификаторы профиля» HotkeyHandler (Profile modifier 1–4): по нажатию RTSS меняет
знак координаты оверлея в глобальном профиле (`PositionX` / `PositionY`, операция XOR с `-2`: `1` ↔ `-1`).
Отрицательная координата — отступ от правого или нижнего края, поэтому оверлей держится за угол при любом разрешении.
Срабатывает сразу, без перезапуска, и запоминается; компактная строка догоняет нижний край в течение полсекунды. Установщик занимает два свободных модификатора; если все четыре
уже заняты, клавиши угла не назначаются. Оверлей можно и просто перетащить мышью на превью экрана в окне RTSS.
Если у игры свой профиль RTSS (не Global), позиция берётся из него и клавиши угла на эту игру не действуют.

Поменять позже: RTSS → **Setup** → **Плагины** → **HotkeyHandler.dll** → **Настроить**, или просто запустите
`install.bat` ещё раз.

### MSI Afterburner

Afterburner не обязателен. Если он стоит — пользуйтесь им для разгона и вентиляторов как обычно. Но у него есть свой
оверлей (галочки «Показывать в ОЭД» на вкладке мониторинга), который накладывается на этот. Установщик выключает
только эти галочки; если Afterburner был запущен — перезапускает его. `uninstall.bat` вернёт их обратно.

Для видеокарт **NVIDIA RTX 20 / 30 / 40 / 50** для разгона и андервольта рекомендуем
[NV-UV](https://github.com/christianp403-spec/NV-UV) и [NV-UV-Play](https://github.com/christianp403-spec/NV-UV-Play).

### Журналы и повторный запуск

- Журнал установки: `%ProgramData%\RTSS-Overlay-Preset\install.log`.
- Отчёт о найденном железе: `%ProgramData%\RTSS-Overlay-Preset\hardware-report.json`.
- **После обновления RTSS** запустите `install.bat` ещё раз: обновление RTSS возвращает его старые файлы
  LibreHardwareMonitor (со старым драйвером WinRing0, который блокируют антивирусы).
- **Удаление:** `uninstall.bat` — возвращает файлы и настройки RTSS (и Afterburner) к состоянию до первой установки.
  Драйвер PawnIO остаётся (им пользуются и другие программы); удалить его можно в «Параметры → Приложения».

Запуск без вопросов: `install.bat -Lang ru -Font Bahnschrift -Style Compact -Defaults`.

## Ручная

Всё то же самое руками.

1. **Драйвер PawnIO.** Запустите `payload\pawnio\PawnIO_setup.exe` и установите (официальный подписанный
   установщик, тот же, что на [pawnio.eu](https://pawnio.eu)).
2. **Закройте RTSS** (значок в трее → Exit).
3. **Скопируйте файлы** в `C:\Program Files (x86)\RivaTuner Statistics Server\Plugins\Client\LHMDataProvider\`
   с заменой (старые лучше сначала сохранить в сторону):
   - всё из `payload\lhm\`
   - `payload\exporter\Exporter.dll`
   - `payload\pawnio\IntelMCHBAR.bin` и `payload\pawnio\AMDFamily17.bin`
4. **Соберите оверлей под свой ПК** — PowerShell **от администратора**, в папке архива:
   ```powershell
   powershell -ExecutionPolicy Bypass -File installer\Make-Overlay.ps1 -Font Bahnschrift
   ```
   Появится `Документы\rtss-overlay-preset.ovl`. Скрипт ничего не меняет в системе, только читает датчики.
   Скопируйте файл в `RTSS\Plugins\Client\Overlays\`.
   Рядом появится `rtss-overlay-preset-icons.png` (стрелки компактной строки) — скопируйте **оба** файла.
   В файле оба вида; `-Style Compact` — сразу показывать компактную строку, `-Key 0x13` — переключать клавишей Pause
   вместо Scroll Lock (код клавиши Windows).
5. **Включите оверлей:** запустите RTSS → **Setup** → вкладка **Плагины** → поставьте галочки **OverlayEditor.dll**
   и **HotkeyHandler.dll** → выделите OverlayEditor → **Настроить** → **Оверлеи → Загрузить** → `rtss-overlay-preset.ovl`.
6. **Настройки RTSS:** в главном окне — **On-Screen Display rendering mode: Raster 3D**; в Setup → Основные —
   **Отображать целое значение частоты кадров** и **Запускать в минимизированном состоянии**.
7. **Горячие клавиши:** Setup → Плагины → HotkeyHandler.dll → Настроить.
8. **Afterburner** (если есть): на вкладке «Мониторинг» снимите у всех датчиков «Показывать в ОЭД».

## Проверка

Запустите любую игру (или `DesktopOverlayHost.exe` из папки RTSS). Если строка RAM показывает частоту без таймингов —
ваш процессор пока не поддерживается для таймингов, остальное работает. Если пусто в половине ячеек — проверьте,
что установлен PawnIO.

Если что-то не так — запустите `installer\Detect.ps1 -Export` (PowerShell от администратора) и приложите
`installer\hardware-report.json` к issue.
